Server-Side Business Rules Enforced

  • 1. Active Membership Gate: Only authenticated athletes with an active, unexpired membership plan can book classes.
  • 2. Plan Concurrency Quota: Starter allows 2 active bookings, Tiger Pro allows 5, and Apex VIP allows 15 concurrent bookings.
  • 3. Strict Class Capacity Lock: Uses MySQL row-level locking (FOR UPDATE) inside a transaction to prevent exceeding max_capacity. Try Olympic Weightlifting tomorrow (seeded at 4/5 spots) to test reaching capacity!
  • 4. Duplicate Prevention: Prevents the same member from booking the same class twice on the same date.
